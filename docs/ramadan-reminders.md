# Ramadan reminders
Independent opt-in settings in Ramadan → bell icon. Suhoor and iftar each support 0–60 minute lead. Uses shared repository and adjusted civil Hijri dates, six-day rolling horizon; independent of prayer reminder enablement. Separate IDs and Android channels; no native adhan service for Ramadan reminders. iOS retains earliest 60 combined requests to stay under platform limit, without background replenishment. Android WorkManager refreshes periodically, not guaranteed. Coincident prayer and Ramadan alerts remain separate notifications. Exact mode uses existing prayer preference. Tests added, not executed.
