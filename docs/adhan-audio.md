# Local adhan library
Settings → Записи азана. User selects a standard or Fajr recording (MP3/WAV/M4A, maximum 15 MiB). The recording is copied into private application support storage using a bounded read and temporary-file replacement. No external storage permissions or network downloads are needed. Preview and stop use audioplayers; playback is disposed on leaving the screen. No bundled third-party recordings. This iteration does not play user recordings from AlarmManager/WorkManager or the lock screen. Android custom notification audio requires a dedicated native URI/channel strategy; iOS custom notification sound has platform restrictions. Verify playback of all formats and restart persistence on devices. Web is unsupported for import.
