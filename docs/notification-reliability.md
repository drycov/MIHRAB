# Notification reliability
Refresh replaces matching notification IDs before removing obsolete IDs, avoiding the initial cancel-all gap. Replacement is not transactional: partial failures remain possible. Current foreground coordinator serializes refreshes in one isolate only. Before introducing WorkManager, implement cross-isolate ownership or a native single-writer scheduler, stable date-based IDs, and durable atomic configuration. Background scheduling is not enabled in this version. Test exact alarm permission revocation, partial scheduling failure and reboot on a physical device.
