# Android media playback
Native foreground media service supports explicit user-initiated full recording playback from Settings → Записи азана → Фоновое прослушивание. MediaSession exposes stop/pause-as-stop, notification stop action, transient audio focus, partial wake lock through MediaPlayer and cleanup on completion/error. It refuses playback under DND, silent/vibration ringer mode, disabled notifications or zero notification volume. Android restrictions and OEM behavior still apply. The existing scheduled notification sound path is unchanged. A native alarm receiver and headless scheduler bridge are not implemented in this change; do not claim full scheduled playback.
