# Quran audio v0.7.4
Open headphones in Surah reader. Two reciter editions, playback/pause/stop, seek, verse navigation, single/sequential/repeat modes. Resolves per-ayah metadata through Al Quran Cloud, validates edition, verse and HTTPS Islamic Network CDN URL. Optional bounded in-memory cache (12 MiB per track, 32 MiB total) for current player session only; no persistent offline downloads. Foreground-only playback, stops on lifecycle exit; no media service or background controls. Source documentation: https://alquran.cloud/cdn and https://alquran.cloud/api. Verify actual CDN availability, audio rights, platform playback and build/test before release. No new dependencies.
