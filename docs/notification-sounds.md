# Notification sound profiles
Per-prayer profiles: system notification sound, vibration only (Android), silent. Preview sends an immediate test notification with reserved ID 900. Android channels distinguish prayer, early/start and sound profile because channel sound settings are immutable after creation; system/user overrides still apply. The same saved profiles are consumed by foreground and WorkManager scheduling. No DND bypass. iOS cannot guarantee vibration-only delivery. No adhan recording is bundled: add properly licensed audio and platform resources before introducing an adhan profile. Test on physical devices, including upgrades from legacy channels and silent mode.
