# Stable reminder identities
IDs use a reserved namespace and the civil prayer date, prayer type and early/start flag. The rolling window no longer shifts IDs at midnight. Legacy IDs are recognized for cleanup after successful scheduling. Settings are stored in one versioned JSON preference with legacy read compatibility; desired configuration is persisted before scheduling so a later refresh can retry. SharedPreferences is not a crash-durable transactional database and this does not serialize cross-isolate writers. WorkManager remains disabled until single-writer ownership and platform tests are implemented.
