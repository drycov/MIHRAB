# Quran reader
Uses documented HTTPS Al Quran Cloud endpoints /v1/surah and /v1/surah/{number}/editions/quran-uthmani,{translation}. Validates catalog count/order, edition identifiers, surah and ayah alignment, and nonempty text. No generated verses or bundled translations. Russian ru.kuliev and English en.pickthall selected in reader; source and translation attribution shown. SharedPreferences caches validated responses by surah and edition; offline only after successful fetch, not a full offline download. Search is catalog-only, reading position is explicitly bookmarked. Before distribution verify source terms and translation licensing, actual API availability, Arabic rendering and cache durability. Build and tests not executed.
