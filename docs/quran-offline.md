# Offline library
Sequential download of 114 surahs per selected translation, using existing validated local text cache; stop between requests and resume by skipping valid cache entries. Offline search across cached verses, Arabic mark normalization, translation and reference search, max 200 results. Audio downloads persist in app-support directory on IO platforms, 12 MiB per track and 256 MiB quota, serialized disk operations and temporary-file replacement. Explicit clear audio and remove selected text edition. Audio downloaded individually, not entire reciter collection. Text still uses SharedPreferences, not SQLite; no background downloads, no full-text index, no cloud sync. API availability, licensing, build and tests not verified.
