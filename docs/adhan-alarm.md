# Native adhan alarm foundation
Adds exact AlarmManager scheduling, persisted native alarm records, duplicate consumption, five-minute lateness limit, boot/update restore and foreground service launch with fallback notification on start failure. Native scheduler MethodChannel is registered in MainActivity only. The optional foregroundNative parameter is deliberately disabled by default: WorkManager's headless engine does not yet register this plugin, so enabling it in production would permit double sound or stale native alarms after a background refresh. Existing URI-backed scheduled notification behavior remains active. Next: package scheduler as a local Flutter plugin registered in both engines, reconcile cancellation and silent fallback, and validate real-device delivery. No build/device tests performed.
