# Localization v0.9.0 foundation
Supported locales ru/kk/ar/en, system locale selection, persisted manual override, Flutter Material delegates, Arabic RTL via framework. Core navigation, settings, prayer screen and selected reader/diary/library labels translated; untranslated text falls back to Russian. Religious text/translation editions unchanged. Notifications, native widgets, onboarding and detailed feature messages are not fully translated; plural/date formatting and native localization remain follow-up. Uses SDK flutter_localizations. Translations need native-speaker review. Build, dependency resolution, RTL device tests and unit tests not executed.
