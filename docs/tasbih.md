# Digital tasbih
Access from Quran or Dua toolbar. Presets 33/99/100 and custom goal 1–9999, five dhikr/count modes, optional haptic feedback, persisted active count and up to 100 completed sessions. One JSON preference stores count and history; serialized writes prevent repeated completion or concurrent lost increments in the foreground controller. Reset and goal changes discard unfinished progress after confirmation. History deletion requires confirmation. Goals are user counting tools, not religious prescriptions. No cloud sync, no additional dependencies. SharedPreferences is best-effort local persistence, not a durable transactional database. Tests added, not executed.
