# Native localization v0.9.4
Version-1 widget snapshot adds optional language/labels and localized city, prayer and Hijri names. Android and iOS read optional fields, Russian fallback for previous snapshots; RTL layout for Arabic snapshots. Native adhan playback and fallback read legacy Flutter SharedPreferences locale or supported system locale. No alarm IDs or timing changes. Android channel IDs retained; existing channel names may not update. Widget gallery metadata and first-run placeholders are not fully localized. Flutter/native builds and device tests not run. Legacy preference interoperability requires device verification.
