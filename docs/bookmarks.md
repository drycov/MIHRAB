# Favorites and bookmarks
Unified local storage for surah, ayah and dua references. Toggle from catalog or detail screen, open Favorites from Quran or Dua toolbar, filter by content type and collection, search title/reference/collection, create and delete named collections, move saved items. Deleting a collection keeps its bookmarks. Existing last-read position is independent. Quran navigation uses cached catalog/verses or network; a bookmark does not automatically download text. SharedPreferences JSON with serialized writes; no cloud synchronization, no new dependencies. Tests added, not executed.
