# iOS WidgetKit
Integrated PrayerWidget target, embedded extension, App Group entitlements and Flutter implicit-engine channel. Small and medium sizes, seven-day snapshot, timeline entries at prayer boundaries and selected-city midnight, stale fallback, private diary count. Proposed App Group group.kz.mihrab.mihrab.widgets and extension bundle kz.mihrab.mihrab.PrayerWidget must be registered with the user's Apple Developer team; select the same team on both targets and regenerate profiles. No team ID assumed. iOS 15 minimum. Xcode project edited directly; Xcode build, signing, simulator and device tests not performed. WidgetKit controls actual refresh timing.
