# Home widgets
Android native RemoteViews/AppWidgetProvider reads a private seven-day snapshot published by Flutter at launch, resume, selected city/date/madhab and Hijri changes, and diary edits. Next prayer uses absolute epoch and selected city timezone. System widget refresh requested every 30 minutes (not an exact alarm). Diary progress applies only to snapshot's first day; opening app refreshes. No background Flutter invocation; after seven days schedule expires until app reopened. Widget tap opens app. Android light/dark resource variants. iOS WidgetKit target and App Group signing are not integrated in this release; see ios/WidgetPrototype/README.md. No new dependency. Android build and launcher test not performed.
