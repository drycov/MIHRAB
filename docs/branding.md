# MIHRAB launcher icon
Emerald #103D32 and gold #D9BD85, mihrab arch and crescent. Android API 26+ adaptive background/foreground; API 33+ monochrome layer; vector fallback for older devices. Existing density PNGs are retained but anydpi resources take precedence on supported Android versions. iOS source artwork is branding/mihrab-icon.svg; the existing AppIcon PNG catalog is not replaced in this revision. Export opaque RGB PNGs for each Contents.json size before iOS distribution. Verify launcher masks and themed icon on actual devices.

PWA production builds regenerate all four manifest PNGs and favicon from branding/mihrab-icon.svg via tool/generate_web_icons.py (Python standard library). Standard icons match the master transform; maskable variants use the original Android foreground scale with additional safe area. Run `python tool/generate_web_icons.py web` to update source icons for local debug. Vercel and Pages invoke this automatically through build_pwa.py. Existing iOS AppIcon and Android density PNGs are not modified; iOS visual consistency still requires export and device verification.
