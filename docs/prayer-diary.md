# Prayer diary v0.8.0
Open from the prayer screen. Five obligatory prayers, manual on-time/qada/missed/unmarked states, daily summary, date navigation and picker from 2000 to current city date. SQLite database separate from reminder lock; composite date/prayer primary key, transaction update/insert, deletion for unmarked. Personal civil date independent of city; UTC modification timestamps. Android/iOS/macOS supported by sqflite; other platforms show unsupported message. No automatic missed status, no cloud sync, no new dependencies. Domain tests added; database integration, platform build and tests not executed.
