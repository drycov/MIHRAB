# Experimental Android local adhan notification sound
The existing AlarmManager-based notification scheduler uses a content URI for a selected local recording at prayer start. Fajr uses its dedicated file. Early reminders, missing recordings and iOS use system sound. The non-exported read-only provider accepts only standard/fajr paths in app-private filesDir and supports URI grants. Validate that Android's notification service can read the URI, including locked screen, process death, reboot and release builds. No full-length foreground media playback or DND bypass is implemented. Android may truncate or suppress notification audio. Channel settings are user-controlled and immutable once created. Replan after file changes; existing channels may retain cached sound. This is experimental until actual device delivery is confirmed.
